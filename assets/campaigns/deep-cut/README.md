# DEEP CUT — BYMOU independent campaign

Fictional record club. Speculative work, not a commission or published campaign.

Three photographic source elements were created with the built-in ChatGPT image tool. No Higgsfield, paid API or purchases were used for this campaign. The tool did not disclose an exact backend or price. Typography, copy, record mark, crops and five individual compositions were authored separately with Python/fontTools and SVG. Final display assets are WebP, with self-contained SVG originals.

Instrument Serif is licensed under SIL OFL 1.1; see fonts/OFL.txt. Small Arial lettering is stored as vector outlines; no Arial font file is distributed. design.py reproduces the vector layouts using fontTools and a local Arial installation.

Campaign language is English; the surrounding site has EN/FR/IT navigation and explanatory copy. No musicians, music rights, sales, clients or performance results are claimed.
